# WorkoutApp 
WorkoutApp is an iOS application for practicing UI development based on a Sketch design.  
The app uses mock data and does not include business logic, focusing solely on UI implementation. 

## Stack  
- **iOS Version:** 15.4+  
- **Technologies:** Swift, UIKit, CoreAnimation (CAShapeLayer, UIBezierPath), Timer, AutoLayout  
- **UI:** Fully implemented in code using reusable components.  
- **Features:** Resources (colors, fonts, and strings) are stored in a separate file for easy management.
